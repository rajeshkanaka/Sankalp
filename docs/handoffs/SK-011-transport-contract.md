Transport makes one attempt; worker owns revalidation, retries, lease fencing and history. No library-default four-week TTL. Compute TTL from remaining job expiry immediately before dispatch and conservatively allow for transit; already expired/canceled work sends nothing.

`validatePushEndpoint(endpoint): URL` rejects controls/whitespace, backslashes, HTTP, credentials, fragment, nondefault ports, IP literals including legacy forms, trailing-dot/Unicode lookalike hosts and suffix attacks. Candidate provider rules: exact fcm.googleapis.com; exact updates.push.services.mozilla.com; nonempty label-boundary subdomain of push.apple.com. Preserve opaque path/query. These are official-source candidates; actual authorized subscription verification remains SK-017/B04, not claimed by local M4. Edge/WNS and Samsung Internet provider rules are unverified, so do not broaden the allowlist for them.

Resolve A and AAAA concurrently with an attempt-local dns.promises.Resolver. Wait for both; an absent family may return ENODATA, but other failures prevent dispatch. At least one address is required. Reject the whole answer when any address is non-public. Reject mapped/compatible IPv6, NAT64, scopes and malformed forms. Intentional conservative specialized-public exclusions are acceptable; do not fetch registry data at runtime.

Pin only those validated addresses in a custom lookup with no second resolution. Preserve hostname, Host, SNI and certificate validation. Supply a new non-reusing https.Agent with keepAlive:false and explicit empty proxyEnv; destroy it after each attempt. Never use global agent/environment proxy or follow redirects. Start an overall10-second deadline before DNS, shortened by job lifetime. Cancel resolver, abort/destroy request/response and agent on abort/deadline. Every async continuation must reject late dispatch; DNS finishing after cancellation must send nothing. Bound response headers16KiB and discarded body8KiB. 404/410 invalidate only the current subscription generation. Other permanent4xx/3xx are terminal without invalidation.408/429/5xx are retryable with bounded parsed Retry-After. Lost/truncated/oversized response after possible transmission is uncertain; never acceptance. TLS rejection is terminal; DNS or connection failure proven before transmission can be transient. Cancellation before possible transmission is terminal canceled; afterward is uncertain. Unknown raw error details never leave adapter.
