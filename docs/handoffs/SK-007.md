## Implemented

- Added owner-scoped reflection reads and writes using the shared journey/session lock order and one post-lock clock sample. Writes accept opened sessions on active or archived journeys, reject unopened and superseded sessions, use an independent reflection revision beginning at zero when absent, and return safe acknowledgements without note or mood content.
- Added exact idempotent retries, changed-body operation reuse rejection, no-change rejection, and authorized conflict state. Reflection rows and ordered mood rows update atomically in the existing `withUser` transaction.
- Added private journal search with strict query validation, owner-private journey IDs, parameterized literal substring matching that escapes backslash, percent and underscore, exact mood/date/journey intersections, `(practice_date DESC, session_id DESC)` keyset pagination, no total count, and 280-Unicode-codepoint previews. Empty reflection rows retain revision state but stay out of journal results.
- Added reflection-prompt preference reads and writes for the two frozen prompt identifiers.
- Added a plain-text `ReflectionEditor` with exact note preservation, Unicode codepoint counting, five custom mood tags, optional prompts, 900 ms debounced autosave, explicit save, stable transport retries, and visible pending/saved/error states. An uncertain request keeps its exact operation ID, base revision and payload; note/mood editing and ordinary Save stay disabled until the user deliberately retries that envelope.
- Added a two-device conflict view that validates the authorized current record, keeps local and saved note/mood versions visible, and requires “Keep my version” or “Use saved version.” Neither path silently merges content.
- A stale retry whose authorized server record already exactly matches the attempted note and ordered moods is acknowledged as saved at the server revision. `NO_CHANGE` now includes that authorized current reflection, preventing a deliberate “Keep my version” retry from becoming trapped when another device has already saved the same content.
- Added `Journal` with JSON POST filters, cursor loading without duplicate entries, plain-text/whitespace-preserving previews, and links back to owned session details. Added a separate `ReflectionPreferencesEditor` for prompt choices.

No rich text, HTML rendering, public indexing, AI interpretation, session mutation, shared route, migration, navigation, or tracking changes were made.
